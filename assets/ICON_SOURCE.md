# Icon source

The icons are downloaded from the selfh.st icon collection (repository `selfhst/icons`,
served via jsdelivr). No icon was drawn or modified by hand.

| File in this repo | Upstream file | Used for |
|---|---|---|
| `icon.svg` | `svg/portainer.svg` | Default (blue logo, readable on light and dark backgrounds) |
| `icon-light.svg` | `svg/portainer-dark.svg` | Dark-colored logo for light backgrounds |
| `icon-dark.svg` | `svg/portainer-light.svg` | Light-colored logo for dark backgrounds |

Download URLs:

- https://cdn.jsdelivr.net/gh/selfhst/icons/svg/portainer.svg
- https://cdn.jsdelivr.net/gh/selfhst/icons/svg/portainer-dark.svg
- https://cdn.jsdelivr.net/gh/selfhst/icons/svg/portainer-light.svg
